# AgilePoint Server Overview

**Source file**: `Clippings/agilepoint-server.md`

## Summary

Documents AgilePoint Server as the core backend engine responsible for executing and managing workflow processes. Covers its role in process orchestration, task execution, event processing, and integration with external systems.

## Key Points

- Acts as the central processing layer; invisible to end users but critical to all platform operations
- Manages process instances, work items, and system events at runtime
- Connects to external databases, APIs, and enterprise services for data exchange
- Handles security & authentication and data processing
- Supports scalability and enterprise-grade workloads
