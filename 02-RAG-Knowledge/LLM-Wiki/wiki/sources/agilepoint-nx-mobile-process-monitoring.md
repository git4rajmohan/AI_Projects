# AgilePoint NX Mobile App Process Monitoring

**Source file**: `Clippings/AgilePoint NX Mobile App Process Monitoring.md`

## Summary

Documents the process monitoring capabilities within the AgilePoint NX Mobile App. Covers workflow instance monitoring, progress tracking, and task status visibility from mobile devices.

## Key Points

- View running process instances and their execution flow from mobile
- Track workflow progress from start to completion; identify pending and completed steps
- Check status of assigned and related tasks and understand next actions
- Provides real-time visibility into business processes
- Enables faster decision-making and remote oversight of workflows
