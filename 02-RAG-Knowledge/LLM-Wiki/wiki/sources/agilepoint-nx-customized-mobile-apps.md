# AgilePoint NX Customized Mobile Applications

**Source file**: `Clippings/AgilePoint NX Customized Mobile Applications.md`

## Summary

Documents the ability to build fully customized mobile applications through the Mobile App Accelerator. Covers three dimensions of customization — branding, functional, and user experience — and the use cases enabled.

## Key Points

- Three customization areas: branding (logos, themes, colors), functional (features, workflows, behavior), user experience (interface design, usability)
- Supports iOS and Android
- Use cases: internal enterprise apps, field service, customer-facing apps, department-specific workflow apps
- Reduces need for extensive mobile development
- Delivers tailored, scalable mobile solutions
