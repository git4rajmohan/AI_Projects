# Page Builder

**Type**: Module — UI Page Design Tool  
**Parent**: [[nx-portal]]

## What It Is

Page Builder is a visual drag-and-drop design tool within [[nx-portal]] used to create and manage custom portal pages. It enables developers and administrators to design the visual interface of portal pages without writing code.

## Key Capabilities

- Rows/columns layout system for structured page design
- Library of widgets including text, tables, forms, and charts
- Organize pages with folders
- Import/export page configurations for reuse across environments
- Sample pages for fast starting points
- Publish controls and page permissions management
- Supports visual page design without custom coding

## Relationships

- Lives within [[nx-portal]]
- Configured via [[settings]]
- Pages can surface data from [[data-entities]] and application workflows
