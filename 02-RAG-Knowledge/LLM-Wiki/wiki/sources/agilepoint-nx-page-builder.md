# AgilePoint NX Page Builder

**Source file**: `Clippings/AgilePoint NX Page Builder.md`

## Summary

Documents the Page Builder module in the NX Portal. Covers visual page design, layout tools, widget placement, page management, import/export, sample templates, publish controls, and permissions.

## Key Points

- Enables visual creation of custom portal pages without extensive coding
- Layout system uses rows, columns, and configurable styles
- Widgets add content and functional components to pages
- Pages can be organized into folders; import/export supported
- Sample pages (prebuilt templates) available as starting points
- Publish options control when/how pages go live; permissions control user access per page
