# Mobile App Accelerator

**Type**: Feature — Custom Mobile App Builder

## What It Is

The Mobile App Accelerator is a service within [[agilepoint-nx]] for building custom-branded, enterprise-grade mobile applications for iOS and Android. Unlike the standard [[mobile-app]], it enables organizations to create white-labeled apps specific to their brand, function, and user base.

## Key Capabilities

- **Custom Branding** — logos, themes, color schemes — see [[custom-branding]] concept
- **Functional Customization** — application features, workflows, and behavior
- **UX Design** — tailored user interface design
- Supports both iOS and Android
- Multiple distribution options: public stores, enterprise stores, direct

## Distribution Methods

| Method | Description |
|--------|-------------|
| Apple App Store | Public distribution via Apple's app store |
| Google Play | Public distribution via Google's app store |
| EMM / Private Store | Enterprise Mobile Management or internal private store |

## Use Cases

- Corporate-branded internal apps for employees
- Field service apps for operational teams
- Customer-facing branded apps
- Department-specific workflow apps
