# App Builder

**Type**: Module — Application Development Tool  
**Parent**: [[nx-portal]]

## What It Is

App Builder is the low-code application development environment within [[nx-portal]] and [[manage-center]]. It provides visual tools for designing business applications, eForms, and workflows without requiring traditional software development expertise.

## Key Capabilities

- Visual form and eForm design
- Workflow process modeling
- Application configuration and component management
- Deployment tools for publishing completed applications
- Integrates with [[data-entities]] for application data storage

## Access Points

- Accessible directly from [[nx-portal]]
- Also accessible from within [[manage-center]]

## Relationships

- Part of [[nx-portal]]
- Applications built here are deployed and managed in [[manage-center]]
- Applications run within [[work-center]]
- Uses [[data-entities]] for data storage
