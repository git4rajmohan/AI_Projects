# AgilePoint Platform Overview

**Source file**: `Clippings/agilepoint.md`

## Summary

Top-level overview of the AgilePoint platform. Describes AgilePoint as a low-code enterprise application platform for building, automating, and managing business applications and workflows via a visual development environment. Introduces NX Portal as the centralized web interface and lists all core platform components.

## Key Points

- Five core capability pillars: process automation, application development, data management, analytics & reporting, enterprise integrations
- Integrations include Microsoft 365, SharePoint, and Salesforce
- Mobile capabilities provided via [[mobile-app]] and [[mobile-app-accelerator]]
- [[nx-portal]] is composed of: Home Page, Work Center, Manage Center, Analytics Center, Settings, Data Entities, Page Builder, App Builder
