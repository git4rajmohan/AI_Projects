# Mobile App

**Type**: Module — Native Mobile Application

## What It Is

The AgilePoint NX Mobile App is the native iOS and Android application for [[agilepoint-nx]], providing mobile access to enterprise processes, tasks, and workflows. It is a standard app available for all users and complements the [[nx-portal]] web interface.

## Supported Platforms

- **iOS**: iPhone and iPad
- **Android**: Smartphones and tablets

## Main Sections

| Section | Description |
|---------|-------------|
| My Tasks / My Team | View, manage, and complete assigned workflow tasks |
| My Apps | Access and launch available applications |
| Watchlist | Monitor specific process instances |
| My Planned Tasks | View upcoming scheduled tasks |

## Key Capabilities

- **Task Approval** → [[agilepoint-nx-mobile-task-approval]]: Review and approve/reject requests from mobile
- **Process Monitoring** → [[agilepoint-nx-mobile-process-monitoring]]: Track running workflow instances
- **Offline Support** → [[agilepoint-nx-mobile-offline-support]]: Complete tasks without internet; auto-sync on reconnect

## Relationships

- Mobile equivalent of [[work-center]] in [[nx-portal]]
- Powered by [[agilepoint-server]]
- Custom-branded versions built via [[mobile-app-accelerator]]
- Configured via [[settings]]
