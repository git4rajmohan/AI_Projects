# AgilePoint NX Manage Center

**Source file**: `Clippings/AgilePoint NX Manage Center.md`

## Summary

Documents the Manage Center as the administrative hub of the NX Portal. Covers sections for runtime monitoring, application management, access control, and system configuration.

## Key Points

- Six main sections: Dashboard, Runtime Management, Application Management, App Builder, Access Control, System
- Manages user roles, permissions, and access policies
- Runtime Management tracks running process instances, work items, and system events
- System section handles global platform services including notifications
- Also provides access to App Builder for development tasks
