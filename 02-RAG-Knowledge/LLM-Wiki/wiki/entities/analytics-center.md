# Analytics Center

**Type**: Module — Reporting & Analytics  
**Parent**: [[nx-portal]]

## What It Is

The Analytics Center is the reporting and data visualization module within [[nx-portal]]. It enables users to create, configure, and share reports and interactive dashboards based on application and workflow data.

## Key Capabilities

- Create and configure reports via guided wizard (Report Builder); no advanced technical skills required
- Live preview during report design
- Interactive dashboards with drill-down and cross-filtering
- Real-time data visualization using charts and graphs

## Export Formats

Excel · PDF · Word · CSV · JSON

## Relationships

- Lives within [[nx-portal]]
- Draws data from workflows managed by [[agilepoint-server]]
- Configured via [[settings]]
