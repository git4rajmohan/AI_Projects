🤖 ADK Agent Pipeline (Schema Proposal)

The schema is proposed by a Google ADK LoopAgent — a refinement loop of 3 agents that iteratively propose, critique, and validate the schema.

schema_proposal_agent LlmAgent — samples files, proposes node & relationship rules
schema_critic_agent LlmAgent — validates proposal, returns 'valid' or 'retry' with feedback
StopChecker BaseAgent — stops loop when critic says 'valid'
