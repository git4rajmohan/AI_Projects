# AgilePoint Mobile Capabilities Overview

**Source file**: `Clippings/agilepoint-mobile-capabilities.md`

## Summary

Summarizes the full mobile capabilities of the AgilePoint NX platform — both the standard Mobile App and the Mobile App Accelerator for custom-branded applications. Covers distribution options and key mobile use cases.

## Key Points

- Two main mobile offerings: the standard [[mobile-app]] and the [[mobile-app-accelerator]] for custom builds
- Mobile App sections: My Tasks, My Apps, Watchlist
- Mobile App Accelerator supports building for iOS and Android with custom logos, themes, and branding
- Distribution through public app stores (Apple App Store, Google Play) or private enterprise stores
- Enables anytime/anywhere access to workflows and applications
