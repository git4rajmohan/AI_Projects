🧠 AI Mindmap Creator — User Guide

Turn any text, document, or YouTube video into an interactive mindmap — powered by a local LLM.

🐍 Python 3.10+ 🦙 Ollama (local, private) 📊 markmap.js 🖥️ Streamlit UI

💡 What is this app?

AI Mindmap Creator takes any piece of content — a text file, a YouTube video, or text you simply paste in — and turns it into a beautiful interactive mindmap that you can explore, collapse, expand, edit, and download.

Everything runs on your own computer. Your text is sent to a local AI model (Ollama), so nothing leaves your machine and nothing is shared with any cloud service.

  • No sign-ups, no API keys, no cloud costs — the AI runs locally.
  • Three ways to give input: upload a file, paste a YouTube link, or paste text.
  • Two output formats: a standalone HTML mindmap, or the raw Markdown source.

🔄 How it works (in plain English)

Think of the app as a four-step assembly line:

1️⃣ You give contentfile, YouTube link, or pasted text
➜
2️⃣ App reads itextracts clean plain text
➜
3️⃣ Local AI organizes itpicks main topic, branches, details
➜
4️⃣ You see a mindmapinteractive & downloadable

The AI reads your text like a skilled note-taker: it finds the central theme, breaks it into 3–7 major branches, and nests details underneath. Hovering over any node shows a short description of what it covers.

⚡ Two modes to choose from

⚡ Fast Mode — one shot

The AI reads your text once and produces the mindmap in about 30–60 seconds. Great for articles, notes, and simple content. Best when you want a quick result.

🤖 Agent Mode — with a quality check

Three AI "workers" team up: one builds the outline, a second reviews and criticizes it, the first revises it, and this back-and-forth repeats until the outline is approved (up to your chosen number of rounds). Takes 2–5 minutes, but produces noticeably better-organized mindmaps for complex or long content.

🚀 End-to-end walkthrough

Step 1 — Install Ollama (the local AI engine)

Download and install Ollama from ollama.com. After installing, open a terminal and pull a model (this is a one-time download, a few GB):

terminal
ollama serve          :: starts the AI engine (usually auto-starts)
ollama pull gpt-oss:120b    :: downloads a good default model
ollama list                  :: verify the model is installed
💡 Bigger models give better mindmaps but are slower. If things feel slow, try a smaller model like gpt-oss:20b — you can switch models anytime in the app's sidebar.

Step 2 — Set up and start the app

terminal
python -m venv venv          :: create an isolated Python environment
venv\Scripts\activate        :: activate it (Windows)
pip install -r requirements.txt
streamlit run app.py

Your browser opens automatically at http://localhost:8501. The sidebar shows a green ✅ Ollama is running if everything is connected.

Step 3 — Give it something to map

  1. Upload a file — drag in a .txt or .md file (a report, lecture notes, an article).
  2. YouTube link — paste any video URL; the app fetches the video's transcript automatically.
  3. Paste text — copy anything (an email, meeting notes, a chapter) into the text box.

Step 4 — Generate the mindmap

Click the big 🚀 Generate Mindmap button (Fast Mode) or 🤖 Run Agent Pipeline (Agent Mode) and wait. A spinner shows progress. In Agent Mode, you'll see a live log of the review loop as it happens.

Step 5 — Review, tweak, and save

  • Explore — click any node to collapse/expand its branches; drag to pan; scroll to zoom.
  • Edit — open "📝 View / Edit Markdown", change any heading, and the mindmap re-renders instantly.
  • Download HTML — saves a self-contained file that opens in any browser with no internet needed. Perfect for sharing.
  • Download Markdown — saves the raw text version, ideal for docs, Notion, or Obsidian.
✅ That's the whole loop: content in → mindmap out → edit if needed → download and share.

🤖 Agent Pipeline — Implementation Detail

Implemented in src/agent_pipeline.py. Three cooperating roles, each a separate LLM call with its own system prompt:

AGENT 1 · temperature 0.3

Schema Creator

SCHEMA_CREATOR_PROMPT — analyzes raw text, outputs a strict JSON tree: { "topic", "description", "branches": [ { "title", "description", "subtopics": [...] } ] }. Rules enforced by prompt: 3–7 branches, ≥2–3 subtopics each, 2–3 nesting levels, ≤8-word labels, **bold** key terms, description field per node.

AGENT 2 · temperature 0.2

Schema Reviewer

SCHEMA_REVIEWER_PROMPT — receives the JSON schema + the source text (truncated to 8,000 chars) and grades it on 6 criteria: coverage, balance, conciseness, hierarchy depth, accuracy, JSON validity. Returns { "approved": bool, "feedback": string }.

AGENT 1 (revised) · temperature 0.3

Schema Reviser

SCHEMA_REVISER_PROMPT — receives the previous schema + reviewer feedback and outputs the revised JSON. Loops back to Agent 2 for re-review.

AGENT 3 · deterministic

Mindmap Creator

Implemented as the pure-Python schema_to_markdown() function rather than an LLM call — deterministic and reliable. Maps schema depth to heading levels: topic→#, branches→##, subtopics→###/####/…, and appends each node's description as an HTML comment <!-- … --> (markmap renders these as hover tooltips).

Review loop pseudocode

schema  = LLM(SCHEMA_CREATOR_PROMPT, text)              # Agent 1
history, approved = [], False

for i in 1..max_iterations:                             # default 3 (slider 1–5)
    review = LLM(SCHEMA_REVIEWER_PROMPT, schema, text)  # Agent 2
    history.append(review.feedback)
    approved = review.approved
    if approved: break
    if i < max_iterations:
        schema = LLM(SCHEMA_REVISER_PROMPT, schema, review.feedback)  # revise
    else: log("⚠️ max iterations reached — using last schema")

markdown = schema_to_markdown(schema)                   # Agent 3 (deterministic)
return { markdown, schema, iterations, review_history, approved }

🔑 Key Implementation Notes

OpenAI-SDK ↔ Ollama bridge

The openai client is instantiated with base_url="http://localhost:11434/v1" and a dummy api_key="ollama". Ollama natively implements the OpenAI chat-completions schema, so no adapter code is needed. All LLM access (Fast Mode, Agent 1–3) funnels through client.chat.completions.create().

LLM output hardening

Both generation paths defensively strip markdown code fences (```json … ```) before json.loads(), since models occasionally wrap structured output in fences despite "output only raw JSON" instructions. Prompts use low temperature (0.2–0.3) to reduce hallucination and keep structure stable.

Hover tooltips via HTML comments

Node descriptions travel as trailing HTML comments in the Markdown (## **Branch** ). markmap renders these as hover tooltips — a zero-extra-dependency way to attach metadata to nodes.

Streamlit state management

Results persist via st.session_state keys (markdown_output, agent_schema, agent_review_history, …). Widget keys are prefixed (fast_/agent_) so identical input widgets can coexist across tabs. The live pipeline log streams through a progress_callback that appends to a st.empty() container.

Why Agent 3 isn't an LLM call

Although a MINDMAP_CREATOR_PROMPT exists, the pipeline deliberately uses the programmatic schema_to_markdown() converter — an LLM rewrite step could drop or mutate approved content, and a pure string transform is deterministic and instant.

Standalone export

The template inlines the markmap JS bundle + rendered Markdown JSON into one HTML file. The download button serves that exact string, so the exported file is a portable, offline-openable artifact — no server, no build step.
