# AgilePoint NX

**Type**: Platform  
**Category**: Low-code enterprise application platform

## What It Is

AgilePoint NX is a low-code enterprise application platform for building, automating, and managing business applications and workflows using a visual development environment. It is the flagship product of AgilePoint, combining process automation, application development, data management, analytics, and mobile capabilities in a unified platform.

## Key Capabilities

- **Process Automation** — Design and automate business workflows via visual process modeling
- **Application Development** — Build form-based enterprise applications with low-code tools
- **Data Management** — Built-in data storage and modeling via [[data-entities]]
- **Analytics & Reporting** — Monitor workflows and application performance via [[analytics-center]]
- **Enterprise Integrations** — Microsoft 365, SharePoint, Salesforce, external APIs/databases
- **Mobile** — Native mobile app and custom app builder for iOS and Android

## Platform Architecture

| Layer | Component | Description |
|-------|-----------|-------------|
