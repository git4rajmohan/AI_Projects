# AgilePoint NX Data Entities

**Source file**: `Clippings/AgilePoint NX Data Entities.md`

## Summary

Documents the Data Entities module — the built-in data storage and modeling system within AgilePoint NX. Covers entity types, field/record structure, relationships, and the role of Data Entities in reducing dependence on external databases.

## Key Points

- Functions like a database within the platform: entities = tables, fields = columns, records = rows
- Two entity types: Standard (predefined by AgilePoint) and Custom (user-defined)
- Supports relationships between entities via dependent fields for linked data retrieval
- Reduces dependency on external systems (databases, SharePoint, CRM)
- Enables building data-driven workflows and forms entirely within the platform
