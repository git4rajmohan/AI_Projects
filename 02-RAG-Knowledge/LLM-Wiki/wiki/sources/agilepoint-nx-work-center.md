# AgilePoint NX Work Center

**Source file**: `Clippings/AgilePoint NX Work Center.md`

## Summary

Documents the Work Center module of the NX Portal — the primary daily workspace for end users to manage tasks, monitor processes, and access applications. Covers all main sub-screens and capabilities.

## Key Points

- Central workspace for task and workflow management
- Seven sub-screens: Overview, Tasks, Processes, My Apps, Delegations, External Apps, Statistics
- Supports task delegation and external app integration
- Statistics screen provides visual dashboards of workload and process activity
- Users can start new application instances from the My Apps section
