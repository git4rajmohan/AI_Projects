# Collaboration Center

**Type**: Module — Communication & Collaboration  
**Parent**: [[nx-portal]]

## What It Is

The Collaboration Center is the communication hub within [[nx-portal]], providing users with access to messaging, announcements, system notifications, and an integrated social feed.

## Components

| Component | Description |
|-----------|-------------|
| AgilePoint Messenger | Real-time user-to-user communication |
| Announcements | Organizational updates and important messages |
| System Notifications | Alerts for tasks, workflows, and system events |
| Viva Engage News Feed | Social collaboration via Microsoft Viva Engage integration |

## Relationships

- Lives within [[nx-portal]]
- System Notifications tied to [[work-center]] task and workflow events
