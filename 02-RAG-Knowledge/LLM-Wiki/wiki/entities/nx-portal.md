# NX Portal

**Type**: Module — Primary Web Interface

## What It Is

The NX Portal is the centralized web interface that serves as the primary entry point for interacting with [[agilepoint-nx]]. It organizes all platform functionality into distinct modules accessible from a unified interface.

## Core Purpose

- Central workspace for application access, task management, process monitoring, and system configuration
- Hosts all major platform modules under a single navigable interface
- Serves as the IDE-equivalent for business users, developers, and administrators alike

## Portal Modules

| Module | Type | Primary Use |
|--------|------|-------------|
| [[nx-home-page]] | Dashboard | Entry point; top apps, banners, navigation shortcuts |
| [[work-center]] | User workspace | Task and process management |
| [[manage-center]] | Admin | Runtime monitoring, access control, configuration |
| [[app-builder]] | Development | Application design and building |
| [[page-builder]] | Development | Custom portal page design |

| [[settings]] | Configuration | Platform-wide and module-specific settings |
| [[tour-guide]] | Onboarding | Interactive guided walkthroughs |

## Relationships

- Mobile equivalent is [[mobile-app]]
