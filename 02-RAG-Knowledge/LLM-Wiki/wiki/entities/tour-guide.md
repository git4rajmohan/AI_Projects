# Tour Guide

**Type**: Feature — Interactive Onboarding  
**Parent**: [[nx-portal]]

## What It Is

Tour Guide is an interactive, step-by-step onboarding feature within [[nx-portal]] that guides new users through the platform interface and key features. It helps users quickly discover the portal layout, navigation, and functionality without relying on external documentation.

## Key Features

- Sequential step-by-step walkthroughs highlighting portal elements
- Visual tooltips and highlights on key interface areas
- In-context guidance that keeps users inside the platform
- Covers major portal modules and navigation patterns

## Use Cases

- First-time user onboarding
- User training without external documentation
- Reducing time-to-productivity for new team members

## Relationships

- Lives within [[nx-portal]]
- Designed to introduce all major modules including [[work-center]], [[manage-center]], [[analytics-center]]
