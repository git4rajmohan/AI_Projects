# Low-Code Development

**Type**: Platform Capability / Development Pattern

## Definition

Low-code development is the core design philosophy of [[agilepoint-nx]]. It enables non-technical business users and citizen developers to build, automate, and manage enterprise applications using visual tools — without requiring traditional programming expertise.

## How It Manifests in AgilePoint NX

| Capability | Tool | Description |
|------------|------|-------------|
| App & form design | [[app-builder]] | Visual form builder and workflow designer |
| Portal page design | [[page-builder]] | Drag-and-drop portal page layout |
| Data modeling | [[data-entities]] | Visual table/field definition, no SQL |
| Report creation | [[analytics-center]] | Guided Report Builder wizard |
| Mobile app creation | [[mobile-app-accelerator]] | Custom mobile app without coding |

## Benefits

- Faster time-to-value compared to traditional development
- Empowers business teams to own their applications
- Reduces dependency on IT/developer resources
- Enables rapid iteration and change management
- Scales application development across the organization
