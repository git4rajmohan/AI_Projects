# AgilePoint NX Mobile App Task Approval

**Source file**: `Clippings/AgilePoint NX Mobile App Task Approval.md`

## Summary

Documents the task approval feature of the AgilePoint NX Mobile App. Covers how users review requests, take approval actions, and provide comments — all from mobile devices.

## Key Points

- Users can review workflow request details including associated forms and data before deciding
- Approval actions available: Approve, Reject, with optional comments/inputs
- Accessible anytime and anywhere through the mobile interface
- Speeds up decision-making and reduces delays in approval workflows
- Enables continuous process flow regardless of location
