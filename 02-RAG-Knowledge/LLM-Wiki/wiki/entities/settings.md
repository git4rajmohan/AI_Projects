# Settings

**Type**: Module — Platform Configuration  
**Parent**: [[nx-portal]]

## What It Is

Settings is the centralized configuration module within [[nx-portal]], providing system administrators with controls for configuring every major platform component.

## Configuration Areas

| Area | Description |
|------|-------------|
| Portal | Global NX Portal display and behavior settings |
| Work Center | Task and process workspace settings |
| Manage Center | Administration and monitoring configurations |
| App Builder | Application development environment settings |
| Data Entities | Data storage and entity configuration |
| Page Builder | Portal page design settings |
| Analytics Center | Report and dashboard settings |
| Mobile | Mobile app behavior and access settings |
| SharePoint Online | Microsoft SharePoint integration settings |
| Tenant | Organization-level platform settings |
| Log Files | System logging and audit log settings |

## Relationships

- Configures all major modules in [[nx-portal]]
- Mobile settings affect [[mobile-app]] behavior
- Tenant settings are platform-wide
