# AgilePoint NX App Store Distribution

**Source file**: `Clippings/AgilePoint NX App Store Distribution.md`

## Summary

Documents the ability to publish custom mobile apps built with the Mobile App Accelerator to public app stores (Apple App Store and Google Play). Covers the distribution process and benefits.

## Key Points

- Custom-branded mobile apps can be published to Apple App Store and Google Play
- Distribution process: build via [[mobile-app-accelerator]] → apply branding/config → publish to store → users download
- Supports standard app store installation and automatic update workflows
- Enables wide reach and leverages trusted public app platforms
- Provides scalable distribution to users worldwide
