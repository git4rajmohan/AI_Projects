# Work Center

**Type**: Module — Primary User Workspace  
**Parent**: [[nx-portal]]

## What It Is

The Work Center is the primary daily workspace for end users within [[nx-portal]]. It provides a unified view of tasks, process instances, and available applications, allowing users to manage their workday from a single interface. The [[mobile-app]] mirrors this functionality for mobile users.

## Main Sub-Screens

| Screen | Description |
|--------|-------------|
| Overview | Summary of tasks and activity; workload insights |
| Tasks | View, manage, and complete assigned workflow tasks |
| Processes | Monitor running process instances and their status |
| My Apps | Access available applications; start new process instances |
| Delegations | Assign or manage delegated tasks and ownership |
| External Apps | Access integrated external applications |
| Statistics | Visual dashboards and metrics; task and process analytics |

## Relationships

- Lives within [[nx-portal]]
- Mobile equivalent: [[mobile-app]] (My Tasks, My Apps, Watchlist sections)
- Configured via [[settings]]
- Powered by [[agilepoint-server]]
