# AgilePoint NX Collaboration Center

**Source file**: `Clippings/AgilePoint NX Collaboration Center.md`

## Summary

Documents the Collaboration Center module of the NX Portal. Covers four communication components: AgilePoint Messenger, Announcements, System Notifications, and Viva Engage News Feed.

## Key Points

- AgilePoint Messenger enables real-time user communication
- Announcements module displays organizational updates
- System Notifications alert users to task and workflow events
- Viva Engage integration brings social/enterprise social feed into the portal
- Centralizes all communication tooling in one portal location
