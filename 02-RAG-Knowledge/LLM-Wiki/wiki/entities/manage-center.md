# Manage Center

**Type**: Module — Administration & Operations  
**Parent**: [[nx-portal]]

## What It Is

The Manage Center is the administrative hub of [[nx-portal]], providing system administrators and operations staff with tools to monitor, manage, and configure the entire AgilePoint NX platform.

## Main Sections

| Section | Description |
|---------|-------------|
| Dashboard | System activity overview; key metrics and status |
| Runtime Management | Monitor running process instances, tasks, system events |
| Application Management | Deploy, configure, and manage application lifecycle |
| App Builder | Access to application development tools |
| Access Control | Users, roles, permissions, and access policies |
| System | Global platform services and configuration |

## Key Capabilities

- Monitor and manage all running workflows and process instances
- Control user access and permissions across the platform
- Manage deployed applications and their configurations
- Configure platform-level services including notifications

## Relationships

- Lives within [[nx-portal]]
- Contains access to [[app-builder]]
- Configured via [[settings]]
- Provides runtime view of [[agilepoint-server]] operations
