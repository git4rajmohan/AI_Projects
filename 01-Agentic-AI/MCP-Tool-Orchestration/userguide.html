What is MCP App?

MCP App is a chat assistant that can do things, not just talk. A normal chatbot can only write text. This app can also act: it can check the real time, open spreadsheets, read files on your disk, browse websites, draw diagrams, query databases and analyse pictures.

It does this by connecting a Large Language Model (LLM) 窶・the "brain" 窶・to a set of tool servers 窶・the "hands". The brain decides which tool to use and when; the hands do the actual work and hand the results back so the brain can answer you properly.

邃ｹ・・The name "MCP"
MCP stands for Model Context Protocol 窶・an open standard that lets AI apps plug into tools. Because it's a standard, any MCP-compatible tool server can be added to this app without changing the app's code.

How the conversation flows (plain English)

  1. You type a message
    e.g. "What time is it now?" 窶・it appears in the chat, and a 笞呻ｸ・Processing bar with a Stop button shows.
  2. The brain thinks
    The message (plus recent history) is sent to the AI model. It decides: "To answer this I need the get_current_time tool."
  3. The hands do the work
    The app asks the right tool server (a small helper program) for the time. You'll see a 肌 block in the chat showing the call.
  4. The result goes back to the brain
    The tool's answer ("7:38 AM, Eastern Time") is fed back into the AI.
  5. You get a real answer
    The AI writes: "It's currently 7:38 AM (Eastern Daylight Time, America/New_York)", plus a footer listing the tools used. If it needs more tools, steps 2窶・ repeat (up to a safe limit of 20 rounds).

Getting started

  1. Start the app
    Double-click mcp_app\run_app.bat. A browser tab opens at http://localhost:8502. (Log output: C:\Temp\streamlit_out.txt.)
  2. Start the tool servers
    Sidebar 竊・箕・・Manage Servers 竊・make sure the toggles you want are ON. (If you edit the list, click 売 Restart at the bottom of the sidebar.)
  3. Send your first message
    Type hi 竊・friendly reply. On the first message the app shows "Starting MCP servers窶ｦ" and all enabled servers turn 泙 READY in the sidebar.
  4. Try a tool
    Type What time is it now? 竊・a 肌 tool block appears and you get the real current time.
笨・Which buttons do what
売 Restart = stop & start all tool servers (use after changing servers/settings).
卵・・Clear = wipe the conversation but keep servers running.
竢ｹ・・Stop (in chat) = cancel the reply that is currently being generated.

Tips for better results

  • Give exact paths. "Read C:\Temp\mcp_test_data\sales.xlsx" works better than "read my sales data".
  • Name the sheet. "Read the Sales sheet from 窶ｦ" avoids guessing.
  • One task per message. Chained tasks work, but clear single steps get cleaner tool calls.
  • Watch the 肌 blocks. They show exactly what the AI did 窶・the fastest way to understand an unexpected answer.
  • Use 卵・・Clear when switching topics so old context doesn't confuse the model.
  • Big files? Ask "how many rows does this file have?" first, then read in chunks 窶・outputs are capped to protect the chat.

chat_engine.py wires registry/router/orchestrator and owns lifecycle. agno_orchestrator.py builds the Agno Agent (+ vision agent), applies xlsx tool-scoping, draw.io intercept and turn limits. tool_router.py executes calls wrapped in retry_async(retries=2, exceptions=(ProcessTimeoutError, TransportError)) 窶・ policy/validation errors fail fast, untouched.

Native Ollama /api/chat adapter (Bearer header only when api_key set 窶・local Ollama sends none) and OpenAI-compatible adapter with Bearer + _normalize_base_url. prompting.py generates the system message incl. exact Excel tool names (read_sheet_names, read_sheet_data, write_sheet_data, read_sheet_formula, write_sheet_formula) to stop models hallucinating names.

src/mcp_app/mcp/ 窶・MCP plumbing
server_manager.py ﾂｷ client.py ﾂｷ transports/{stdio,http,ws}.py

Starts all enabled servers concurrently (start_all), injects per-server env (EXCEL_MAX_ROWS/SQL_MAX_ROWS from limits via merged_env.setdefault so explicit per-server env: wins), routes tools/call. http.py is a stub (Phase 5: Streamable HTTP); ws.py optional (Phase 6).
