# AgilePoint NX Portal Home Page

**Source file**: `Clippings/AgilePoint NX Portal Home Page.md`

## Summary

Documents the NX Portal Home Page — the main dashboard and entry point into the platform. Covers application shortcuts, portal banners, navigation shortcuts to all major modules, and user actions available from the home screen.

## Key Points

- Displays Top Applications (frequently used) and New Applications (recently added)
- Portal Banners show announcements, updates, and quick links
- Direct navigation shortcuts to Work Center, Manage Center, App Builder, Analytics Center, Collaboration Center, Settings, and Help
- Users can start apps, access tasks, build apps, and configure settings from the home page
