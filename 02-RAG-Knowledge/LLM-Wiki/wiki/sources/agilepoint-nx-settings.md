# AgilePoint NX Settings

**Source file**: `Clippings/AgilePoint NX Settings.md`

## Summary

Documents the Settings screen in the NX Portal. Covers module-specific configuration options, administrative settings, tenant settings, mobile settings, SharePoint Online integration, and log file access.

## Key Points

- Central configuration area covering: Portal, Work Center, Manage Center, App Builder, Data Entities, Page Builder, Analytics
- Administrative settings for system-wide platform configuration
- Tenant settings for multi-tenant deployments
- Mobile settings for configuring the mobile app experience
- SharePoint Online App Settings for integration management
- Log Files section for accessing server logs
