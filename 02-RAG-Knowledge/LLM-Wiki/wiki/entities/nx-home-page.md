# Portal Home Page

**Type**: Module — Entry Dashboard  
**Parent**: [[nx-portal]]

## What It Is

The Portal Home Page is the main dashboard and first screen users see upon accessing [[nx-portal]]. It provides quick access to applications, displays important announcements, and offers shortcuts to all major portal modules.

## Key Features

- **Top Applications** — Quick access to frequently used applications
- **New Applications** — View recently added/available apps
- **Portal Banners** — Announcements, updates, and quick links
- **Navigation Shortcuts** — Icon-based shortcuts to all major modules

## Modules Accessible from Home Page

[[work-center]] · [[manage-center]] · [[app-builder]] · [[analytics-center]] · [[collaboration-center]] · [[settings]]
