# AgilePoint NX Mobile App Overview

**Source file**: `Clippings/agilepoint-mobile-app.md`

## Summary

Documents the AgilePoint NX Mobile App — a native mobile application for iOS and Android providing task management, application access, process monitoring, and offline workflow participation comparable to the Modern Work Center.

## Key Points

- Four core sections: My Tasks/My Team, My Apps, Watchlist (process monitoring), My Planned Tasks
- Supports offline eForm submission; tasks queued in Outbox and auto-synced when connectivity restores
- Available on both iOS and Android
- Mirrors functionality of the web-based Modern Work Center
