# AgilePoint NX Analytics Center

**Source file**: `Clippings/AgilePoint NX Analytics Center.md`

## Summary

Documents the Analytics Center module in the NX Portal. Covers report creation, data visualization, interactive dashboards, and export capabilities.

## Key Points

- Enables creation and configuration of reports based on application and workflow data
- Supports drill-down and cross-filtering interactions on dashboards
- Report Builder uses a guided wizard with live preview; no advanced technical skills required
- Export formats: Excel, PDF, Word, CSV, JSON
- Supports sharing reports via links
