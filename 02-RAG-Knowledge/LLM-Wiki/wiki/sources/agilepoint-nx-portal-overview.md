# AgilePoint NX Portal Overview

**Source file**: `Clippings/agilepoint-nx-portal.md`

## Summary

Describes the NX Portal as the central web interface and primary entry point for AgilePoint NX. Lists all navigation modules available within the portal and their purposes. Covers portal capabilities for interacting with applications, tasks, processes, and tools.

## Key Points

- NX Portal is the main workspace for users to access applications, manage tasks, monitor processes, and configure the system
- Ten portal modules: Home Page, Work Center, Manage Center, App Builder, Page Builder, Analytics Center, Collaboration Center, App Store, Settings, Help Center
- Users can start applications, interact with eForms, and participate in workflows directly from the portal
