# AgilePoint NX Mobile App Offline Support

**Source file**: `Clippings/AgilePoint NX Mobile App Offline Suppor.md`

## Summary

Documents offline functionality in the AgilePoint NX Mobile App. Covers use cases for disconnected environments, how offline data is stored and queued, and the automatic synchronization process.

## Key Points

- Users can access and complete eForms without internet connectivity or AgilePoint Server access
- Offline data stored locally on device; queued for sync
- Automatic synchronization occurs upon network reconnect — updates central system and maintains consistency
- Key use cases: field operations in remote areas, limited/unreliable network environments
- Removes dependency on continuous internet access for task execution
